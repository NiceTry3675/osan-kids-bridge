# 2분 시연영상 콘티와 내레이션 대본

- 화면: 보호자 휴대폰(375×812)·기관 관리자 화면(데스크톱)·포스터 무대를 한 장의 큰 캔버스에 놓고, 카메라가 지금 일이 일어나는 곳으로 확대·이동한다. 누르는 곳에는 커서와 물결 표시
- 소리: 팀이 직접 내레이션을 녹음해 얹는다. 그래서 화면 글자는 최소로: 왼쪽 위 장면 표시, 보호자 질문의 한국어 번역(말풍선), 오른쪽 아래 '줄인 것' 표시만
- 색: 크림 바탕·코랄·초록 (발표자료와 같은 톤)
- 장면마다 '무엇이 AI이고 무엇이 검증인지'가 보이게 한다

> 자동 녹화: `presentation/build/record-demo.js`가 아래 콘티대로 약 1분 54초짜리 영상을 만든다.
> - `node record-demo.js` → `presentation/osan-kids-bridge-demo.mp4` (제출용)
> - `PROMPTER=1 node record-demo.js` → `presentation/osan-kids-bridge-demo-prompter.mp4` (녹음용: 화면 아래에 그 장면의 대본이 뜬다)
>
> 장면 길이는 대본을 초당 5.2음절로 읽는 시간보다 짧아지지 않게 맞춘다(대본은 스크립트의 `SCENES`). 대본을 고치면 다시 녹화하면 길이도 따라 바뀐다.
> 녹화 전에 상담 답 2개와 공고 보완 초안을 실제 API로 받아 두고(두 번째 상담 답은 영상과 같은 추가 안내를 잠시 저장해 받은 뒤 지움), 편성안은 `capture.js plan`이 받아 둔 `build/render/plan-result.json`(발표자료 캡처와 같은 결과)을 쓴다. 녹화 중에는 모두 2.5초 만에 돌려준다. API는 `npm run demo`로 새로 띄운 상태여야 한다.

## 준비 (녹화 전)

```bash
# 1) API (시연 데이터, 기준 시각 2026-10-15 10:00 고정)
npm run demo -w @osan-kids-bridge/program-api
# 2) 보호자 웹 (API에 연결)
VITE_DATA_MODE=api VITE_API_BASE_URL=http://127.0.0.1:8787 npm run dev -w @osan-kids-bridge/guardian-web
# 3) 기관 대시보드 (보호자 질문 탭이 API를 읽음)
VITE_API_BASE_URL=http://127.0.0.1:8787 npm run dev -w @osan-kids-bridge/institution-dashboard -- --port 5174
```

- `.claude/launch.json`에 같은 설정이 있다(program-api-demo, guardian-web-api, institution-dashboard).
- 번역 포스터와 회차별 이미지는 `apps/program-api/data/local/translated/`에 있어야 한다(없으면 `npm run poster -w @osan-kids-bridge/program-api`, 운동회 베트남어는 `--demo-fault`로 오류 주입판).
- API를 다시 켜면 공고는 처음 상태(추가 안내 없음)로 돌아간다. 녹화 스크립트는 시작할 때 추가 안내와 보호자 질문 기록을 비운다.

## 녹음 팁

- 녹음용 영상(`-prompter.mp4`)을 틀어 두고 화면 아래 대본을 따라 읽는다. 장면이 바뀌기 전에 끝나도록 대본 길이를 맞춰 두었다.

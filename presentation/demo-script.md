# 2분 시연영상 콘티

- 화면: 휴대폰 크기(375×812) 보호자 웹 + 기관 대시보드, 터미널 한 장면
- 자막: 한국어 자막(심사위원용). 보호자 화면은 베트남어
- 장면마다 '무엇이 AI이고 무엇이 검증인지'가 보이게 한다

> 자동 녹화본: `presentation/build/record-demo.js`가 아래 콘티대로 1분 41초짜리 초안(`presentation/osan-kids-bridge-demo.mp4`)을 만든다. 직접 찍을 때는 아래 준비와 장면을 따른다.

## 준비 (녹화 전)

```bash
# 1) API (시연 데이터, 기준 시각 2026-10-15 10:00 고정)
npm run demo -w @osan-kids-bridge/program-api
# 2) 보호자 웹 (API에 연결)
VITE_DATA_MODE=api VITE_API_BASE_URL=http://127.0.0.1:8787 npm run dev -w @osan-kids-bridge/guardian-web
# 3) 기관 대시보드 (보호자 질문 탭이 API를 읽음)
VITE_API_BASE_URL=http://127.0.0.1:8787 npm run dev -w @osan-kids-bridge/institution-dashboard -- --port 5174
```

- `.claude/launch.json`에 같은 설정이 있다(program-api-demo, guardian-web-api, institution-dashboard).
- 보호자 웹에서 화면 언어를 Tiếng Việt로 고르고 시작한다. 이전 대화가 남지 않도록 새 탭에서 연다.
- 번역 포스터는 `apps/program-api/data/local/translated/`에 있어야 한다(없으면 `npm run poster -w @osan-kids-bridge/program-api`).
- API를 다시 켜면 공고는 처음 상태(추가 안내 없음)로 돌아간다. 보호자 질문 기록을 비우려면 `apps/program-api/data/local/demo-session/questions/`를 지운다.
- 상담 답은 10~25초 걸린다. 영상에서는 기다리는 부분을 빨리 감기하고 자막에 '실제 응답 시간 약 15초'라고 적는다.

## 촬영 팁

- 브라우저 확대 100%, 모바일 크기. 보호자 웹 상단의 '초안 언어' 띠는 개발 빌드 표시이므로 그대로 둬도 되고, 자막으로 '번역 초안'이라고 밝혀도 된다.
- 터미널 글자는 크게(18pt 이상). 로그의 ✗/✓ 줄에서 잠깐 멈춘다.
- 상담 질문은 미리 복사해 두고 붙여 넣는다(타이핑 시간 절약).

# 잇다, 오산

다문화 자녀 프로그램 연결 및 참여환경 개선 서비스 · 팀 다담(임준현 · 이선우 · 김채현 · 박소영)

**부모님의 질문이 다음 프로그램이 되는 곳.** 오산 다문화가정 부모님이 편한 언어(쉬운 한국어 · Tiếng Việt · 中文)로 아이에게 맞는 프로그램을 찾고, 공고에서 답을 못 찾은 것은 이름 없이 기관에 알립니다. 기관은 모인 질문으로 공고를 보완하고, 익명 통계와 질문으로 다음 프로그램을 편성합니다. 부모님이 쓰는 **보호자 웹**, 기관이 쓰는 **기관 대시보드**, 둘이 함께 쓰는 **공고 서버**로 이루어져 있습니다.

## AI 에이전트 넷

모델은 고르고 쓰기만 하고, 사실과 숫자는 코드가 확인하며, 결정은 사람이 합니다.

| 단계 | 에이전트 | 하는 일 | 어디서 |
|---|---|---|---|
| 읽기 | ① 포스터 통번역 | 기관 포스터의 디자인은 두고 글만 베트남어·중국어로 바꾼 뒤, 다른 모델과 코드가 다시 읽어 날짜·숫자·QR을 대조하고 틀린 곳만 고쳐 다시 만듦 | `npm run poster` → 보호자 웹의 번역 포스터, 기관 검수 화면 |
| 연결 | ② 상담 | 검수된 공고로만 답하고 인용은 코드가 원문에서 다시 찾음. 공고에 없는 것은 기관에 물을 한국어 문장으로 만들고, 부모님이 원하면 이름 없이 기관에 알림 | 보호자 웹 'AI에게 물어보기' (`/agent/chat`) |
| 편성 | ③ 공고 보완 | 모인 질문으로 공고에 덧붙일 안내 초안을 쓰고, 기관만 아는 값은 빈칸으로 남김. 담당자가 채워 덧붙이면 보호자 상세와 상담 답에 바로 쓰임 | 기관 대시보드 '보호자 질문' (`/admin/programs/{id}/improve`) |
| 편성 | ④ 편성 | 익명 통계·못 찾은 질문·지금 공고로 다음 프로그램의 대상과 근거를 고름. 요일·시간·장소·닿는 가정 수는 `packages/planning`이 계산 | 기관 대시보드 'AI 편성 제안' (`/admin/planning/propose`) |

## 폴더

| 폴더 | 내용 |
|---|---|
| `apps/guardian-web` | 보호자 모바일 웹. 탐색·조건·상세·번역 포스터·AI 상담·신청/문의 안내 |
| `apps/institution-dashboard` | 기관 대시보드(데스크톱 우선). 공고·번역 포스터 검수, 보호자 질문과 공고 보완 도우미, AI 편성 제안, 수요 현황·일정 추천 |
| `apps/program-api` | 공고 서버. 공고 구조화(Gemini)·검수·판정 API, 포스터 통번역 검증 루프, 상담 에이전트, 기관용 관리자 API(공고 보완·편성 도우미) |
| `packages/ui` | 두 앱이 함께 쓰는 디자인 토큰(`tokens.css`), 서체, 화면 요소(`components.css`), 시트, 화면 언어 고르기 |
| `packages/planning` | 편성 계산: 익명 수요(시연은 합성 400가정) 집계·소수 셀 억제, 요일·시간·장소 추천(`recommend`). 대시보드와 서버의 편성 도우미가 함께 씀 |
| `packages/phone-preview` | 두 앱을 휴대폰 틀에 담은 단일 HTML 시연 페이지 만들기(`npm run preview`) |
| `docs/` | 기관 대시보드 계획서, 정적 유저플로우 보드(`docs/userflow`) |
| `presentation/` | 발표 덱·시연영상을 만드는 스크립트, 시연 콘티, 개요서 (덱·영상·그림은 커밋하지 않음) |

맨 위의 `program_connection_spec_v2_2.md`는 보호자 웹과 서버가 따르는 서비스 명세, `보호자_페르소나_가설_v3.md`는 페르소나 가설입니다.

## 시작하기

Node 20 이상이 필요합니다. 저장소 맨 위에서 한 번만 설치합니다(npm workspaces).

```bash
npm install
npm run check            # 모든 앱 타입 검사 → 테스트 → 빌드
```

### 에이전트까지 띄우기

터미널 셋에서 공고 서버, 보호자 웹, 기관 대시보드를 차례로 띄웁니다.

```bash
# 1) 공고 서버 (8787): 시연 공고 25건, 기준 시각 2026-10-15 10:00 고정, 관리자 API 켬
npm run demo -w @osan-kids-bridge/program-api
# 2) 보호자 웹 (5173): 서버에 연결
VITE_DATA_MODE=api VITE_API_BASE_URL=http://127.0.0.1:8787 npm run dev -w @osan-kids-bridge/guardian-web
# 3) 기관 대시보드 (5174)
VITE_API_BASE_URL=http://127.0.0.1:8787 npm run dev -w @osan-kids-bridge/institution-dashboard -- --port 5174
```

- 공고 검색·상세·기관 검수 화면은 키 없이 돌아갑니다. 시연 공고는 추출·요약까지 끝난 결과가 커밋되어 있습니다.
- 에이전트(상담·공고 보완·편성)는 Vertex AI의 Gemini를 부르므로 서비스 계정 키가 필요합니다. `apps/program-api/.env.example`을 `.env.local`로 복사해 `GOOGLE_APPLICATION_CREDENTIALS`에 키 파일 경로를 적습니다. 포스터를 새로 번역하려면 `OPENAI_API_KEY`도 필요합니다. 키 파일과 `.env.local`은 커밋하지 않습니다.
- 서버를 다시 켜면 시연 공고는 처음 상태로 돌아갑니다. 명령과 API는 [`apps/program-api/README.md`](apps/program-api/README.md)에 있습니다.

### 서버 없이 화면만 보기

```bash
npm run dev:guardian     # 보호자 웹: 앱 안의 가상 공고 (AI 상담·번역 포스터는 서버가 있어야 보임)
npm run dev:dashboard    # 기관 대시보드: 수요 현황·일정 추천·데이터 안내 (공고 관리·두 도우미는 서버가 있어야 씀)
npm run preview          # 시연 페이지 2개 → dist-preview/ (휴대폰 틀, 끌어서 넘기기)
```

### 로컬 데이터 (`apps/program-api/data/local`)

실제 기관 포스터 원본(`inbox/<ID>/poster.*`)과 번역 포스터·회차별 검증 기록(`translated/`)은 이용 조건을 확인하기 전까지 git에 올리지 않고 이 폴더에만 둡니다. 이 폴더가 없으면 포스터 이미지(보호자 웹의 '내 언어로 바꾼 포스터'와 상세의 포스터, 기관 검수 화면의 포스터 칸)만 빠지고, 검색·상세·상담·공고 보완·편성은 그대로 됩니다. `npm run demo`가 쓰는 시연 사본(승인, 덧붙인 안내, 부모님이 알린 질문)도 이 폴더의 `demo-session/`에 쌓입니다. 덱과 시연영상을 다시 만들 때도 이 폴더가 있어야 합니다([`presentation/README.md`](presentation/README.md)).

예전처럼 각 앱 폴더 안에 `node_modules`가 남아 있다면 지우고 맨 위에서 다시 설치하세요. 앱별 `package-lock.json`은 맨 위 `package-lock.json` 하나로 합쳤습니다.

## 디자인 규칙(요약)

- **형광펜 노랑은 “아직 확인되지 않은 것”에만** 씁니다(비용 미상, 기관 확인 필요, 문의처 없음, 상담 언어 미상). 장식으로 쓰지 않습니다.
- 신청 상태 네 가지는 색과 함께 항상 글자와 점 모양(채움·빈 원·네모)으로 구분합니다.
- 화면 언어는 각 언어의 이름으로 늘 화면 맨 위에 보이고, ‘다른 언어’에서 이름으로 찾을 수 있습니다. 제공하지 않는 언어도 검색되면 “아직 제공하지 않아요”라고 알려 줍니다.
- 공개 빌드에는 검수된 화면 언어만 열립니다. 베트남어·중국어 초안은 개발·시연 빌드(`npm run dev`, `VITE_DATA_MODE=demo`)에서만 고를 수 있습니다(명세 9장 6항).
- 폭 320px에서도 가로 스크롤 없이 읽히고, 누를 곳은 44~48px 이상입니다. 화면은 밝은 모드 하나만 씁니다(기기가 다크 모드여도 같은 색).
- 서비스 계정 키 같은 비밀값은 커밋하지 않습니다(루트 `.gitignore`).

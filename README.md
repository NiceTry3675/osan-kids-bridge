# osan-kids-bridge

오산시 지역현안 기반 AI·SW 경진대회 출품작. 다문화가족 보호자가 자녀에게 맞는 지역 프로그램을 찾아 신청처로 가도록 돕고, 운영기관에는 수요에 맞는 일정·장소를 추천합니다.

| 폴더 | 내용 |
|---|---|
| `apps/guardian-web` | 보호자 모바일 웹 (기능 1) |
| `apps/institution-dashboard` | 기관 수요·일정 추천 대시보드 (기능 2) |
| `apps/program-api` | 공고 구조화(Gemini)·검수·판정 API. 보호자 웹이 쓰는 서버 |
| `docs` | 기획 문서 |

각 폴더의 README에 실행 방법이 있습니다. 서비스 계정 키 같은 비밀값은 커밋하지 않습니다(루트 `.gitignore`).

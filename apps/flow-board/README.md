# 유저플로우 보드 (실제 화면)

보호자 웹과 운영기관 대시보드의 유저플로우를 7화면씩 보여 주는 보드입니다.
그림이 아니라 휴대폰 틀마다 실제 앱(시연 빌드)이 돌아가므로, 틀 안에서 눌러 보고 스크롤할 수 있습니다.

| 보호자 | 운영기관 |
| --- | --- |
| 01 첫 화면 · 02 홈 · 03 조건 넣기(시트) · 04 결과 · 05 상세 · 06 신청·물어보기(시트) · 07 내 언어 안내가 없을 때 | 01 수요 현황 · 02 조건 고르기(시트) · 03 작은 집계 가림 · 04 추천 조건 · 05 추천 결과 · 06 추천 자세히(시트) · 07 데이터 안내 |

## 실행

```bash
npm run dev -w @osan-kids-bridge/flow-board    # 두 앱을 시연 모드로 빌드한 뒤 보드를 띄움
npm run build -w @osan-kids-bridge/flow-board
```

## 구조

- `scripts/embeds.mjs`: 두 앱을 시연 데이터로 빌드해 `src/generated/`에 문자열로 둡니다(커밋하지 않음). 보호자 웹은 해시 주소로 빌드합니다.
- `src/frame.ts`: 틀 하나의 문서. 앱보다 먼저 도는 스크립트가 저장소를 틀 전용 메모리로 바꾸고 시작 주소를 맞춥니다.
  그래서 첫 화면(소개 전)과 홈(소개 후)처럼 서로 다른 상태의 같은 앱을 나란히 띄울 수 있습니다.
- `src/drive.ts`: 시트·결과·다른 탭 화면은 사람이 누르듯 단계를 눌러 도착합니다.
- `src/flows.ts`: 화면 목록, 각 화면의 시작 상태·누를 단계·설명. 화면을 바꾸려면 여기만 고치면 됩니다.
- 틀은 화면에 가까워질 때 하나씩 띄웁니다. ‘처음 상태로’는 그 틀만 다시 시작합니다.

`docs/userflow/`의 정적 보드(PNG 원본)는 그대로 둡니다.

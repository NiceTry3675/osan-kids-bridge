# 보호자 화면 다국어 게시 기준

## 이번 결정

- 목표 화면 언어는 쉬운 한국어, 베트남어, 중국어다. 화면 언어는 검색 조건이나 참여 자격을 바꾸지 않는다.
- 현재 베트남어·중국어 UI 문구는 **검수 전 초안**이다. 명세 v2.2 9장 6항에 따라 **공개 빌드에서는 고를 수 없고**(‘번역 검수 중’으로만 표시), 개발·시연 빌드에서만 초안 안내와 함께 고를 수 있다. 검수가 끝나면 `src/i18n/policy.ts`의 `UI_REVIEW`를 바꾸고 아래 기록을 남긴다.
- 공고별 제목·대상 원문·소개·미확인 사유처럼 서술형 문구의 번역은 원문의 사실과 대조해 승인한 경우에만 확정 정보로 표시한다. 검수본이 없으면 그 언어의 핵심 안내가 없다는 사실과 대신 확인할 경로를 먼저 알리고, 서술형 문구는 ‘한국어 원문’으로 표시해 접어 둔다. 날짜·시간·비용·신청 상태처럼 구조화된 값의 UI 표기는 선택한 언어로 바꾸되 사실은 같아야 한다. 서술형 문구 일부만 번역한 결과를 완전한 번역으로 소개하지 않는다.
- 화면 언어, 기관의 실제 상담·수업 언어, 외부 신청 페이지의 언어는 서로 다른 정보다. 마지막 두 항목은 원문이나 기관 확인 근거가 없으면 지원 여부를 단정하지 않는다.
- 원문이 바뀌면 관련 번역의 승인을 해제하고 다시 대조한다. 시연 공고·번역 초안을 실제 공고의 검수본으로 취급하지 않는다.

## 게시 전 확인 기록

실제 공고마다 아래 기록을 남긴다. 현 저장소에는 승인된 실제 공고가 아직 없다.

| 항목 | 기록할 내용 |
|---|---|
| 공고와 원문 | `program_id`, 기관, 원문 URL, 게시·재이용 권한, 원문 확인일 |
| 사실 대조 | 대상 구분과 제한, 자녀 나이·학년, 동반 조건, 필요한 한국어 수준, 모든 회차·장소, 비용, 신청 기간·방법 |
| 언어 정보 | 화면별 요약 문구, 기관의 확인된 지원 언어, 신청 페이지의 확인된 언어, 각각의 미상 여부 |
| 검수 | 언어별 번역 작성자, 원문 사실 대조자, 언어 최종 검수자, 승인일, 검수한 원문 버전 |
| 변경 | 원문 변경일, 영향받은 문구, 번역 재검수·재승인 상태 |

검수자는 화면에서 실제로 보이는 목록·상세·오류·신청 안내를 각 언어로 확인한다. 특히 숫자, 날짜, 시간, 무료/비용 미상, 신청 중/예정/마감/미상, ‘학년 일치’와 ‘별도 자격 확인 필요’가 원문과 같은 뜻인지 대조한다. 번역 문구의 변수 누락은 `translation-review.test.ts`가 검사하지만, 의미와 자연스러움에 대한 사람의 검수를 대신하지 않는다.

## 아직 필요한 사람과 데이터

- 베트남어·중국어 최종 검수자 지정 및 승인 기록
- 최소 실제 공고 1건의 원문·게시 권한·구조화 사실과 세 언어의 검수본
- 공고별 검수 상태·원문 버전을 프론트엔드에 전달할 데이터 계약

이 세 가지가 채워지기 전에는 다국어 공고 안내를 완료했다고 표시하지 않는다. 시연 공고의 베트남어·중국어 요약은 화면 동작을 보이기 위한 가상 값이며 검수본이 아니다.
